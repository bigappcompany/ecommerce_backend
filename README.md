# zippyflows_backend

## Description

Zippy Flows [Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Installation
npm i --save @nestjs-modules/mailer @nestjs/bull @nestjs/config @nestjs/jwt @nestjs/passport @nestjs/swagger @nestjs/typeorm aws-sdk base64url bcryptjs class-transformer class-validator crypto date-fns dayjs joi lodash moment passport passport-jwt pg razorpay resend slugify typeorm @types/multer

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
